# Arduino Fruit Keyboard

`ArduinoCode.ino` targets an Arduino UNO R3 and exposes six independent keys.
Flash the same sketch onto two boards for twelve keys. Each board sends key
edges over its own USB serial port; sound is generated by the browser at
`/keys`.

## Wiring

| Analog pin | Arduino 1  | Arduino 2   |
| ---------- | ---------- | ----------- |
| A0         | Key 1 / C4 | Key 7 / B4  |
| A1         | Key 2 / D4 | Key 8 / C5  |
| A2         | Key 3 / E4 | Key 9 / D5  |
| A3         | Key 4 / F4 | Key 10 / E5 |
| A4         | Key 5 / G4 | Key 11 / F5 |
| A5         | Key 6 / A4 | Key 12 / G5 |

The sketch enables the UNO's internal pull-up on every analog pin. A key is
pressed when its pin is connected to `GND`:

1. Connect one alligator lead from each fruit or conductive pad to its assigned
   analog pin.
2. Connect a separate conductive contact to `GND` and hold that contact while
   touching a fruit. Your body closes the low-voltage circuit.
3. For reliable testing, replace the fruit/body path with a momentary switch
   directly between the analog pin and `GND`.

Only use the Arduino's low-voltage pins. Never connect fruit, a person, or this
circuit to mains electricity. Do not connect 5V directly to GND.

## Upload and connect

1. Open `ArduinoCode.ino` in Arduino IDE.
2. Select **Arduino Uno** and the first board's USB port, then upload.
3. Repeat the upload for the second board. Both boards use the same sketch.
4. Run the web app on localhost or HTTPS in desktop Chrome or Edge.
5. Open `/keys`. Use **Select Arduino 1** for keys 1-6, then **Select Arduino
   2** for keys 7-12. Choose a different USB port in each browser prompt.

The browser and sketch use 9,600 baud on both ports. Opening a port usually
resets its UNO; each connection starts listening automatically and waits for
key events. The page maps the same six event names to the selected board's key
range, so no board-specific firmware is required.

## Serial protocol

Every message is ASCII and newline terminated:

```text
READY:FRUIT-KEYBOARD
DOWN:apple
UP:apple
```

Each pin is scanned and debounced independently, so multiple keys can remain
pressed simultaneously. The browser handles messages split between USB chunks
and multiple messages arriving in one chunk.

## Sensitivity

`TOUCH_THRESHOLD` defaults to `1000`. A direct switch should read near `0` when
closed and near `1023` when open. If a fruit touch is not detected, increase the
threshold slightly. If it triggers while untouched, decrease it. Keep the value
between `0` and `1023` and retest all six inputs after changing it.
